# ⚡ صفقات (Safaqat) - رادار الصفقات والوساطة الذكية في قطاع غزة
### Autonomous AI Deal Radar & Trade Brokering System for Gaza Market

منظومة ذكية متكاملة تعمل بواسطة **وكلاء الذكاء الاصطناعي (AI Agents)** لرصد صفقات السلع والأسعار المحروقة في قطاع غزة لحظة بلحظة، وتحليل فيديوهات ومنشورات التجار بالعامية الغزاوية، وبث التنبيهات الفورية للمشتركين مع حماية المحتوى من التسريب.

---

## 🎯 حلول المشكلات الرئيسية المبتكرة في المشروع:

1. **اكتشاف المتاجر الحالية والجديدة ذاتياً (Autonomous Discovery):**
   * الوكيل يبحث دورياً عبر استعلامات محركات البحث المتقدمة (Google Dorking) ومجموعات فيسبوك الكبرى في غزة.
   * عند ظهور أي صفحة جديدة، يقوم **Gemini AI** بتقييمها وفلترتها والتأكد من أنها متجر تجاري حقيقي في غزة وتصنيفها وإضافتها لقائمة المراقبة تلقائياً.

2. **تحليل فيديوهات العروض الصوتية باللهجة الغزاوية (Multimodal AI):**
   * بما أن 80% من تجار غزة ينشرون عروضهم كفيديوهات سريعة على فيسبوك، يقوم النظام بتنزيل الصوت وتحليله عبر **Google Gemini** لفهم الكلام العامي واستخراج السلعة، السعر بالشيكل، مكان المحل، ورقم الهاتف.

3. **منع تسريب الصفقات (Anti-Leakage Protection):**
   * التنبيهات تُبث عبر بوت تليجرام مع تفعيل ميزة `protect_content=True` التي تمنع إعادة التوجيه (Forwarding)، النسخ (Copy)، أو لقطات الشاشة (Screenshots).

4. **نموذج العمل والاشتراكات (Monetization & Free Trial):**
   * نظام اشتراك تلقائي يمنح المشترك أسبوعاً تجريبياً مجانياً فور الضغط على `/start` ليرى التوفير الحقيقي قبل الدفع.

## 🏗️ هيكلية المشروع (Project Architecture):

```
Safaqat/
│
├── config/
│   ├── __init__.py
│   └── settings.py          # الإعدادات، مسارات المجلدات، والمفاتيح
│
├── database/
│   ├── __init__.py
│   └── db_manager.py        # إدارة قاعدة البيانات SQLite (المتاجر، الصفقات، المشتركين)
│
├── core/
│   ├── __init__.py
│   ├── ai_evaluator.py      # وكيل الذكاء الاصطناعي (Gemini) لتقييم الصفحات وتحليل الفيديوهات
│   ├── media_processor.py   # معالج وتنزيل الصوت من فيديوهات فيسبوك (yt-dlp)
│   ├── discovery_engine.py  # محرك اكتشاف الصفحات الجديدة تلقائياً
│   └── monitor_engine.py    # محرك فحص المتاجر ورصد الصفقات الحالية
│
├── bot/
│   ├── __init__.py
│   ├── telegram_bot.py      # بوت تليجرام للمشتركين (أسبوع مجاني + حماية المحتوى)
│   └── alert_dispatcher.py  # محرك بث الصفقات اللحظي للمشتركين
│
├── scripts/
│   ├── seed_initial_stores.py # تغذية المتاجر الأولية في غزة
│   └── run_test_deal.py       # اختبار محاكاة صفقة محلية باللهجة الغزاوية
│
├── safaqat.db               # قاعدة بيانات SQLite الجاهزة
├── requirements.txt         # الحزم والمكتبات
├── .env.example             # قالب المتغيرات
├── main.py                  # سكريبت التحكم والتشغيل الرئيسي
└── README.md
```

## 🚀 طريقة التثبيت والتشغيل:

### 1. إعداد البيئة ومتغيرات البيئة (.env):
أنشئ ملف `.env` في المجلد الرئيسي (أو انسخ من `.env.example`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_BROADCAST_CHAT_ID=
```

### 2. تثبيت المكتبات (تم تثبيتها بنجاح):
```bash
pip install -r requirements.txt
```

### 3. الأوامر المتاحة في `main.py`:

* **عرض إحصائيات النظام:**
  ```bash
  python main.py status
  ```

* **تشغيل دورة الاستكشاف الذاتي للمتاجر الجديدة:**
  ```bash
  python main.py discover
  ```

* **فحص المتاجر ورصد صفقات جديدة:**
  ```bash
  python main.py monitor
  ```

* **بث الصفقات الجديدة للمشتركين:**
  ```bash
  python main.py broadcast
  ```

* **تشغيل بوت التليجرام للمشتركين:**
  ```bash
  python main.py run-bot
  ```

* **تجربة محاكاة رصد صفقة كاملة:**
  ```bash
  python scripts/run_test_deal.py
  ```
